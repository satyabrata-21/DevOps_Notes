# Networking Fundamentals

| Command | Purpose |
| :---    | :---    |
| `ping`  | Check connectvity your computer to another servise|
|`curl` , `wget`| Download file from internet|
| `netstat`| network statistics |
|  `netstat -tulpn` | show active network connection|
|`ss`| Socket statistics|
|`ss -tulpn`| shows all services listening on specific port|
| `dig <example.com>` | perform DNS lookup|
| `nslookup <example.com>` | show name server lookup |
| `host <example.com>`| show domain and alias name|
| `ping <example.com>`| show icmp echo request and time to live(ttl) |
| `traceroute <example.com>`| Trace route to all destination |
| `tracepath <example.com>`| Simplified traceroute|
| `telnet`| allows a user to remotely access and control another computer over a network using a text-based interface.|
